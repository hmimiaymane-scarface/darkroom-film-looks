# Community looks

Looks made by Darkroom users. To use one: download the `.darkroom` file and drop it onto Darkroom
(or click **Import LUT or look** under *My Looks*).

| Look | Based on | Mood |
|---|---|---|
| Golden Hour Portrait | Portrait 400 | Warm, glowing skin, soft highlights |
| Moody Forest | Chrome Classic | Deep, muted greens with teal shadows |
| Clean Feed | Natural Ace | Bright, crisp and true to life, for social posts |

**Want to add yours?** See [CONTRIBUTING.md](../CONTRIBUTING.md#share-a-look-no-coding-needed). No coding needed.
